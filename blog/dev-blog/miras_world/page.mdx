#### Behind the Scenes: How Mira's World Was Built

Hey dev fam! 👋 Welcome to the first tech deep-dive on *Mira's World*'s dev blog. Today I'm pulling back the curtain on how this very site came to life—because transparency and sharing builds are what we're all about.

Mira's World runs on a clean, modern stack that's fast, flexible, and fun to work with:

- **Next.js** (App Router era) — for blazing-fast performance, server-side rendering where needed, and easy static exports.
- **Tailwind CSS** — utility-first styling that lets me ship beautiful, responsive designs without fighting CSS files.
- **shadcn/ui** — the cherry on top. Not a traditional component library—it's copy-pasteable, customizable primitives built on Radix UI and Tailwind. Perfect for owning your UI without bloat.

I started with a solid Next.js + Tailwind + shadcn starter setup (think `npx create-next-app` vibes, then `npx shadcn init` to add the magic). From there, I layered in custom touches to make it feel like home.

What makes this site extra special? It showcases two of my open-source projects right here:

- **NEXT-static** — a lightweight toolkit/config helper for turning Next.js apps into fully static exports. Great for blogs, portfolios, or docs that don't need a backend.
- **NEXT-blog** — my opinionated blog engine built on Next.js. Markdown/MDX support, syntax highlighting, SEO goodies, and easy theming—all while staying super lightweight.

Fun fact: the entire site is **serverless-friendly** and static-export ready (`next export`). That means zero runtime servers, tiny hosting costs, and perfect deployment to places like **GitHub Pages** (with a simple GitHub Actions workflow to handle the build and push). No Vercel lock-in, no database headaches—just HTML, CSS, and JS flying out fast.

This combo keeps things simple, maintainable, and scalable for a personal site like this. Want to remix it? The repo is open—fork away, PR your improvements, or use it as inspo for your next project.

Curious about any part of the stack or setup? Hit the comments or open an issue on GitHub. Let's geek out together. 🚀
